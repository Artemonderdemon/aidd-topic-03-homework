# Функциональные требования к новой функциональности (Задание №4)

1. Пользователь может создавать персональные элементы списка наблюдения для акции с целевой ценой и условием «выше/ниже».
2. Система автоматически проверяет цены и создаёт уведомление при достижении целевого уровня.
3. Повторное уведомление по одному и тому же сработавшему условию не создаётся до сброса условия.
4. Пользователь может просматривать и отмечать прочитанными свои уведомления.
5. Пользователь может создавать виртуальные портфели.
6. Пользователь может исполнять виртуальные сделки покупки и продажи акций.
7. Система учитывает количество, среднюю цену покупки, денежный баланс, реализованную и нереализованную прибыль/убыток.
8. Пользователь может просматривать историю сделок портфеля.
9. Система автоматически сохраняет историю рыночных цен при обновлении.
10. Пользователь может просматривать историю цен акции и изменения за период.
11. Пользователь может создавать стратегии с условием по цене и действием покупки/продажи.
12. Система автоматически исполняет стратегию при выполнении условия и ведёт журнал исполнений.
13. Стратегия не исполняется повторно до сброса условия.
